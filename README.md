# Guide: Who Takes Which Test, and When

Yoshida EdTech Works / EdTech Gabay　2026年11月19日版 / Version of 19 Nov 2026

## 1. 2つのテスト / The two tests

特定技能介護士の日本語と現場力を、2つのテストで確認します。目的が違うので、受ける順番と対象者を分けます。

We use two tests to check the Japanese and on-the-job skills of Specified Skilled Workers (Kaigo). Their purposes differ, so who takes which, and in what order, differs too.

|  | 指示理解・実行力診断テスト / Instruction Check | N3相当 会話能力判定 / N3 Placement Check |
| --- | --- | --- |
| 目的 / Purpose | 試験に合格しても現場で指示を実行できない原因を探る / Find why a worker who passed the exam cannot carry out instructions | 入国時に、介護の場面でN3相当の会話ができるかを判定する / Judge whether the worker can use N3-level Japanese in care situations |
| 内容 / Content | 連続指示、条件、割り込み後の記憶（全20問）/ Sequences, conditions, memory after interruption (20 items) | 聞く・話す・書く（全10課題）/ Listening, speaking, writing (10 tasks) |
| 所要時間 / Time | 約15分 / About 15 min | 約15分 / About 15 min |
| アドレス / Address | https://shiji-rikai-test.vercel.app/ | (https://n3-level-placement-check.vercel.app/) |

**どちらも診断ではなく目安です。採用・評価・解雇の判断には使わないでください。**

**Both are guides, not diagnoses. Do not use them for hiring, evaluation or dismissal decisions.**

## 2. 誰がどちらを受けるか / Who takes which

| 状況 / Situation | 順番 / Order |
| --- | --- |
| すでに現場で働いていて、指示を実行できないことがある人 / Already working, and sometimes cannot carry out instructions | ①診断テスト → ②必要な人だけ N3判定 / 1) Instruction Check, then 2) N3 Check only if needed |
| 入国前・入国時の新しい人 / New workers before or at arrival | ①N3判定 → ②N3相当に近い人は診断テスト / 1) N3 Check, then 2) Instruction Check for those near N3 level |

理由：診断テストは、日本語の音声をある程度聞き取れることが前提です。入国前の人は、語学が足りないだけで点が低くなることがあります。そのため、新しい人は先に語学（N3判定）を確認します。

Why: The Instruction Check assumes the worker can follow Japanese audio to some degree. Before arrival, a low score may simply reflect language level. So new workers take the language check (N3) first.

**N3判定の公開前は / Until the N3 Check is published:** 入国前の人にも診断テストを使えます。その場合、第1部が低いときは「語学の不足」を疑い、文字表示モードで再実施して比べます。

The Instruction Check can be used for pre-arrival workers in the meantime. If Part 1 is low, suspect a language gap and retake in Text mode to compare.

## 3. N3判定に進む目安 / When to go on to the N3 Check

診断テストのあとで、次のどれかに当てはまる人は、N3判定を受けます。

After the Instruction Check, a worker takes the N3 Check if any of the following applies.

- 第1部（聞き取り・語彙）が「要観察」または「要支援」だった。
- 文字表示モードで再実施しても、点が上がらなかった（語彙や表現の力が足りない可能性）。
- 第3部（時間・条件・優先順位）が低かった（「〜前に」「もし〜たら」などの表現が弱い可能性）。
- Part 1 (listening and vocabulary) was "Watch" or "Needs support."
- Scores did not improve in Text mode (vocabulary or expressions may be lacking).
- Part 3 (time, conditions and priority) was low (expressions such as "before \~" and "if \~" may be weak).

## 4. 受ける時期の目安 / Suggested timing

以下は目安です。施設や研修の都合に合わせて調整してください。

These are suggestions. Adjust them to your facility or training schedule.

| 場面 / Stage | テスト / Test | 目的 / Purpose |
| --- | --- | --- |
| 出国前研修の終わりごろ / Near the end of pre-departure training | N3判定 | 入国前に、語学の不足を見つけて補強する / Find and fix language gaps before departure |
| 入国後、配置の前後 / Around placement after arrival | 診断テスト | 指導のしかたを決める / Decide how to coach |
| 補強のあと、数か月たってから / Some months after support | 同じテストを再受験 / Retake the same test | 変化を確認する / See the change |

再受験は、できるだけ同じ条件（端末・音量・場所・モード・音声の速さ）で行います。

For retests, keep conditions as close as possible (device, volume, place, mode and speech speed).

## 5. 誰が何をするか / Who does what

### 送り出し機関 / Sending organizations

- 出国前に、N3判定を実施します。
- 弱い部分を、出国前研修で補強します。
- 結果を受け入れ施設に渡すときは、本人の同意を得ます。
- Run the N3 Check before departure.
- Reinforce weak areas in pre-departure training.
- Share the result with the receiving facility only with the worker's consent.

### 介護士本人 / Caregivers

- テストは、成績ではなく、助けてもらうためのものです。
- 静かな場所で、最後まで受けます。
- わからないときは、現場で「もう一度お願いします」と言ってよいです。
- The tests are not grades; they help you get support.
- Take them in a quiet place, from start to finish.
- On the job, it is fine to say "Mō ichido onegaishimasu" (please say it again).

### 受け入れ施設 / Receiving facilities

- 診断テストの結果と、N3判定の伴走指示書を、指導計画に使います。
- 指示は、1回1動作、行動する順に、具体的な言葉で伝えます。
- 結果を、採用・評価・解雇には使いません。
- Use the Instruction Check result and the N3 coaching sheet in your training plan.
- Give instructions one action at a time, in the order of action, with concrete words.
- Do not use results for hiring, evaluation or dismissal.

## 6. 結果の扱い / Handling results

- 2つのテストで、**同じID**（本名でなく、IDかニックネーム）を使うと、結果を並べて見られます。
- **診断テストは、ページを閉じると結果が消えます。** 必ず、閉じる前にCSVかJSON、またはPDF（印刷）で書き出します。
- 書き出したファイルには、IDと回答が含まれます。本人の同意のもとで共有し、管理に注意します。
- 結果は、人が確認して使います。1回の結果だけで決めつけません。
- Using the **same ID** (an ID or nickname, not a full name) in both tests lets you view the results side by side.
- **The Instruction Check result disappears when the page is closed.** Always export it as CSV, JSON or PDF (print) first.
- Exported files contain the ID and answers. Share them only with consent and handle them with care.
- A person should review the results. Do not decide from a single result.

## 7. 受けるときの準備 / Before taking a test

- スマートフォンかパソコンのブラウザを使います。インストールは不要です。
- 静かな場所で、音量を聞き取りやすい大きさに固定します。
- 最初に「音を確認する」を押して、日本語の声が聞こえるか確かめます。
- 1人ずつ、約15分、途中で中断しないで受けます。
- 受ける前に、操作の説明だけ行い、問題の内容や答えには触れません。
- Use a browser on a phone or computer. No installation is needed.
- Use a quiet place and fix the volume at a comfortable level.
- Press "Sound check" first to confirm you can hear the Japanese voice.
- Test one person at a time, about 15 minutes, without interruption.
- Explain only how to use the app beforehand; do not touch on the questions or answers.
